# Revisions 957, 958
{{k8s}}

A new revision of Charmed PostgreSQL for Kubernetes has been published in the `16/stable` channel. This release upgrades PostgreSQL to 16.15 and completes the migration of the charm's core internals — TLS, configuration, client relations and the Patroni/cluster code — to the [single-kernel library](https://github.com/canonical/postgresql-single-kernel-library) shared with the VM charm.
