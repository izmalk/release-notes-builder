# Revisions 1218, 1219
{{vm}}

A new revision of Charmed PostgreSQL for machines has been published in the `16/stable` channel. This release upgrades PostgreSQL to 16.15 and completes the migration of the charm's core internals — TLS, configuration, client relations and the Patroni/cluster code — to the [single-kernel library](https://github.com/canonical/postgresql-single-kernel-library) shared with the Kubernetes charm.
